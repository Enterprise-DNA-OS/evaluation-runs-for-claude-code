# Why the free base has no front end

The recurring work is to inspect answer sets, run agreed checks, compare versions and record the evidence behind a decision. Those jobs have named commands and produce documents a team can read. The database stores the history.

A browser application adds live collaboration, trace navigation, interactive charts, mobile access, drag and drop, a sign-in experience and convenient forms. This free base has none of those. Its read-only HTML reports are generated from the records and stay unchanged until regenerated. The local database works without a network, but this is not a mobile or offline-sync application.

Enterprise DNA scopes a web view, authenticated team access, capture integrations or a different stack when building a business's version. The free base stays small: the records, checks, evidence and documents. The person asks the agent to act and receives the result in the conversation.
