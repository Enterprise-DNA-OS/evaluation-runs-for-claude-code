# New view

Ask what decision the report supports. Read the existing views and relevant data. Add a read-only SQL view in a new migration and a section in views.json. Keep run evidence_state beside every saved decision. Use only SELECT statements in report definitions, escape every value with the shared renderer and keep generated reports private. Run npm test, npm run migrate and npm run view. Open the result, inspect its layout, then return the file in chat. No server or action buttons.
