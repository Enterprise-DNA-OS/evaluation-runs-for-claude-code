# Customise

Read CLAUDE.md, the migrations and the existing command first. Confirm the requested field, rule or name in the operator brief. Back up with export to a new private file. Write a new numbered migration, never edit one already applied. Update the CLI, seed, relevant command and tests. Run npm test on its isolated database. Apply npm run migrate to the intended local database only after checking DATA_DIR. Shared business database changes need the operator to name that database and approve the migration. Re-evaluate affected runs. Never silently change a saved result or fabricate review evidence.
